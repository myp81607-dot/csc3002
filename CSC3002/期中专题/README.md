## 使用方式

先读各章的概念与符号解释，再独立做英文原题，最后对照六步解析。书中每题有年份、卷别、原 PDF 页码，以及 lecture 文件代号和实际页码。PDF 自带目录和章节/题目书签。

解析为独立推导的教学答案，未取得官方答案表。原卷中关于流返回、OOP 特征、切片、旧 Stanford 容器与有符号移位的措辞或版本问题已明确说明。2021 原件带他人批注，正文以印刷题面为准，批注不作为官方答案。
